# DR4 — Data Presentation

DR4 will present the four current scores and generate a short evidence-grounded report. It must use only the current DR2 evidence and DR3 results; it must not add unsupported outside facts or investment instructions.

Current inputs:

- [`data/current/`](../data/current/) — per-variable signals and aggregate score output.
- [`src/goldrush2/ai/`](../src/goldrush2/ai/) — existing AI support code that DR4 may build on.

DR4 is not yet implemented. Its requirements remain defined in [`PROJECT.md`](../PROJECT.md).
